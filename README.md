# BookStore MERN Stack Project

## Overview

1. On this web app the user can add, edit or delete their personal
book preferences. 

2. All the operations are saved in a MongoDB Schema.

# Technology-Stack:

* React.js
* Tailwind CSS
* Node.js (Express.js)
* MongoDB

# Installation

1. Paste on Terminal:
```bash 
https://github.com/TsiouMiouPiou/BookStore-MERN.git
```

2. Install Dependencies:
```bash 
npm install
```

3. Change Backend Directory
```bash 
cd backend
```

4. Start Server:
```bash 
npm run dev
```

5. Change Frontend Directory:
```bash 
cd frontend
```

6. Start Frontend:
```bash 
npm run dev
```
